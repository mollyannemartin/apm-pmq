# PMQ Learn With Me

This revision hub now includes a beginner-first 5–10 minute learning system.

Sequence:
1. Meet the idea
2. Connect it to real life
3. Recognise it
4. Build the definition
5. Guided application
6. Retrieve it
7. Explain it
8. Exam bridge

Use "I've got 5 minutes" whenever you need a short session. Progress and weak areas are stored in localStorage on the device/browser.

The longer reading, flashcards, tests, written answer lab and mini mock remain available separately.
